# Приложение для анализа банковских операций
## Описание проекта:
Данное приложение используется для анализа транзакций пользователей. 
Все транзакции хранятся в Excel-файле.
## Установка:

1. Клонируйте проект в свой репозиторий по ссылке:
```
git clone git@github.com:Vitaly9319899520/Cursovay_1.git
```

## Реализованы задачи проекта:
1. В модуле *src/views* создана функция *web_main()*, которая принимает на вход строку с датой и временем в формате 
**DD-MM-YYYY HH:MM:SS** и возвращает JSON-ответ со следующими данными:
    - Приветствие в формате «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» 
в зависимости от **текущего времени** (вспомогательная функция (src/utils/hello_date())).
    - Статистику по каждой карте: последние 4 цифры карты, общая сумма расходов, 
кешбэк (вспомогательная функция (src/utils/kart_user_info())).
    - Топ-5 транзакций по сумме платежа (вспомогательная функция (src/utils/top_transactions())).
    - Курс валют (вспомогательная функция (src/utils/exchange_rate())).
    - Стоимость акций из S&P500 (вспомогательная функция (src/utils/stock_prices())).
2. Модуль *src/utils* содержит набор вспомогательных функций, которые формируют возвращаемые значения
для модуля *src/views*.
3. В модуле *src/services* создана функиция *profitable_cashback*, которая группирует транзакции
по категориям и рассчитывает возможный кэшбек для них.
4. В модуле *src/reports* создана функция *spending_by_category*, которая возвращает траты по заданной
категории за 3 месяца до даты, введенной пользователем. Так же 
создана функция-декоратор *save_report_function*, которая записывает ответ, сгенерированный 
функцией *spending_by_category* в отдельный файл с расширением xlsx.

#### Важно! Для каждого модуля формируется log файл с информацией о ходе выполнения функций.

## Инструкция по работе с программой:
- После скачивания проекта в свой репозиторий, установить необходимые библиотеки и зависимости.
- Создать файл с расширением .env в корне проекта, внести свои API-ключи, согласно файлу env.example
- Откройте модуль *src/main* и введите необходимые данные, например:
```
    date_user = "01-01-2021 12:00:00"
    year_user = "2019"
    month_user = "10"
    category_user = "Супермаркеты"
    date_report = "01.10.2021"
```
- В случае, если данные будут внесены не в том формате, программа выдаст об этом информацию.
- Информация, возвращаемая основными функциями, представлена JSON-ответом, либо DataFrame.

## Тестирование программы ##
В программе реализованы функции тестирования для модулей *views.py, utils.py, services.py, reports.py*
Все тесты расположены в папке *tests*, с названиями *tests_имя тестируемого модуля*

Запуск тестов осуществляется через терминал.

Результаты выполнения тестирования можно посмотреть, выполнив команду в терминале:
```
pytest --cov
```

Готовый отчет с результатами тестов хранится в репозитории в папке:

*htmlcov / index.html*

Сформировать новый отчет командой в терминале:
```
pytest --cov=src --cov-report=html
